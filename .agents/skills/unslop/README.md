# Unslop skill resources

This directory groups the skill definition, its agent metadata, reference
material, and helper scripts:

- [`SKILL.md`](./SKILL.md) describes the skill.
- [`agents/`](./agents/) contains agent metadata.
- [`references/`](./references/) contains guidance and visual examples.
- [`scripts/`](./scripts/) contains supporting utilities.

These are development aids, not application runtime dependencies.
