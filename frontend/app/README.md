# Frontend routes

The Next.js App Router defines the public overview, pricing and audit
confirmation pages, and the live monitoring dashboard.

- [`page.tsx`](./page.tsx) — public landing page.
- [`pricing/`](./pricing/) — plan details and Netlify Forms request.
- [`audit-requested/`](./audit-requested/) — form confirmation.
- [`dashboard/`](./dashboard/) — live scans, findings, sites, and reports.
- [`components/`](./components/) — reusable visual components.
- [`globals.css`](./globals.css) — shared application styles.
