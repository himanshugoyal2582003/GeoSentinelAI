# Demo dataset

This directory contains the compact public Sentinel-2 preview pair used to
document the Pune demo region. It is separate from the OSCD benchmark used for
multispectral model training.

See [`public-sentinel2-pune/README.md`](./public-sentinel2-pune/README.md) for
the image pair and manifest, and
[`docs/labeling-and-training.md`](../docs/labeling-and-training.md) for
training data requirements. The preview PNGs are not analysis-ready COG bands
and their weak labels do not establish illegal activity.
